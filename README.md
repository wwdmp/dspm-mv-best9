# DSPM好きなMVベスト9

DSPMアイドルのMVから、好きなMVベスト9を決めるファンメイドサイト。

https://wwdmp.github.io/dspm-mv-best9/

## 遊び方
1. 推しのグループを選ぶ
2. 予選：好きなMVに♡をつける（9本以上）
3. 準決勝：最大6本から2〜3本を選び、9本に絞る
4. 決勝：1対1で順位を決める
5. 結果をXでシェア（#DSPM好きMV9選）

## ファイル
- `index.html` / `style.css` / `app.js` — サイト本体（ビルド不要の静的サイト）
- `data.js` — 対象MVのデータ
- `mv_list.tsv` — 選別済みMVリスト（原本）
- `og.png` / `og/og.html` — OGP画像とその元HTML

非公式のファンメイドサイトです。動画・サムネイルの権利は各権利者に帰属します。
